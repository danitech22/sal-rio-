# Cálculo de Bônus por Salário em Python

Este projeto é um programa simples em Python que calcula o bônus de um funcionário com base no seu salário. O programa solicita o nome e o salário do funcionário e aplica uma regra de bônus diferente dependendo do valor do salário.  

## ⚙️ Funcionalidades

- Solicita o nome do funcionário.  
- Solicita o salário do funcionário.  
- Calcula o bônus baseado em regras pré-definidas:  
  - Salário menor ou igual a R$2.000 → bônus de 10% do salário.  
  - Salário maior que R$2.000 → bônus de 50% do salário.  
- Exibe o nome, salário e bônus no terminal.  

## 🛠️ Tecnologias Utilizadas

- Python 3
